# P2 开发进展

更新：2026-09-24。分支：`p2/topic-projects`。P1 已验收的单群入口保留；P2 使用独立可执行入口 [README.topics.md](../README.topics.md)。

## 已实现

- 项目白名单、显式 `/topic new <projectKey> <名称>` 命令、原消息 ID 去重；普通消息不创建群或任务。
- 原生 App Server `thread/start` 传入项目 ID、真实项目根目录及当前桌面工具连接；保存任务 ID 后校验身份并命名。
- QIU 机器人身份创建含本人的私有普通群，核验群及本人成员，再激活群、项目、任务绑定。
- 单写者 JSON 注册表与逐群独立 P1 账本；已保存资源 ID 后可从下一步接续。创建响应不明时不盲目重试，核实 ID 后有离线修复入口。
- 多群路由原有状态、停止、追加、结果与审批控制器；共享 host 仅对注册、项目白名单且原生身份匹配的任务接续桌面工具。
- 项目目录内 Markdown 索引及原生对话文字记录，每分钟刷新；私人记录目录默认 Git 忽略。

## 当前验证范围

本机离线专项覆盖同项目两话题、跨项目话题、重复投递和重启、已知及未知创建结果接续、按群路由与审批隔离、host 动态任务身份、项目记录与飞书创建请求结构。9 月 24 日三轮受控现场验证已建立 FEISHU 项目 A/B 两个群和原生任务，以及 `p2test` 项目 C 的独立群和任务；本人和 QIU 入群、群消息往返、A 的多轮上下文与桌面→群追问、三组项目记录隔离、显式接续去重，以及三条任务重新载入后的桌面工具连接均已核对。话题 A 经共享进程恢复后沿用原资源。B 群首次消息暴露了桌面短暂撤销连接证明时立即失败的问题；已加提交前有限等待，当前运行进程尚未加载。专项 55 项、全仓单元测试 475 项、TypeScript 类型检查和 tsup 构建通过。现场证据及尚待项见 [P2 验证记录](desktop-p2-validation.md)。
