## 已验证的核心

同一原生项目与桌面对话的飞书文字收发、桌面接续、持久队列与消息去重、状态/追加/定向停止、支持的审批交互与取消、保存结果取回、受控故障暂停及恢复普通桌面。Windows 登录、启动、正常退出保持关闭、手动重入、模型设置切换和延迟退出回执均有现场证据。

运行基线 `63d3ba7` 于 2026-10-16 完成 P4 约定范围验收：一个既有群、一个所有者。五分钟关闭证明为连续 304.295 秒/47 条原生样本，实际延迟退出回执等待 7.986 秒；最终独立清理 26 项通过。公开仓库不携带个人账本、原始会话或本机运行证据。

本版新增的安装准备工具只读探测工具目录、生成新配置，不参与模型执行。它另有自动回归与打包检查；不把这些测试写成已在其他用户电脑完成现场安装。

## 需要单独验收

- 别的桌面版本、升级后的二进制或工具目录。版本字符串相同也可能有不同 SHA；不可关闭校验。
- 更多群、更多所有者、更多项目或启用新话题。首个受管部署固定单群并关闭新建。
- Lark 国际租户及其他操作系统。
- 长时间持续运行。既有验收主要是有界窗口，不等于数天或数周的可靠性证明。

## 不承诺

桌面全部消息镜像、图片附件输入、多用户服务器、断电后的任意自动恢复、重复投递的绝对零风险、任意 App Server 版本兼容、并发双端独立隔离。正常退出会保持关闭；故障恢复到普通桌面表示消息渠道暂停，不等于 Bridge 已恢复处理消息。

共享后台与桌面工具接线依赖本机版本特性和本地信任边界。它不是云端托管服务，也不是对官方接口未来兼容性的保证。[OpenAI App Server 文档](https://learn.chatgpt.com/docs/app-server)说明了底层协议；本项目只承诺这里列明的自身验证范围。
