# 兼容性与支持边界

## 当前发布：v0.10.0

Windows x64、Node.js 22 LTS、单个配置所有者。维护机器上的 Codex `26.1013.4894.0` / 自带 CLI `0.163.0-alpha.10.2` 已完成当前接线核对；具体程序 SHA、工具目录和原生归属仍须逐机验证。

本版支持显式配置的单聊主控、入口群和登记话题群；单聊直接收发、保存结果取回、单聊创建话题及主控与话题结果独立已完成现场验证。基础多群收发、状态、追加、中断后自动接续、支持的审批与结果取回沿用此前版本验证。最新启动修复另完成真实 Windows 重启后的自动接入及约十五分钟、448 份样本的有限健康观察，18 项核对通过；该次只读观察未提交模型输入，不能写成又完成一轮重启后模型收发。

发布范围是上述已验证能力的初步正式版本，并非任意环境的全面可靠性保证。没有统一话题改名、归档、停用、解绑、删除或清空队列命令。删除绑定对话可能阻断全局启动；各群对话独立但同项目文件可共享。全部操作及管理边界见[用户手册](user-guide.zh.md)。

登录自动启动依赖当前用户登录和本机准入检查；正常退出保持关闭。新开机恢复保留旧记录，不重放旧请求；同次开机异常、任意睡眠/断电恢复及长期无人值守仍不作保证。以下旧版本记录仅说明历史验证范围，不替代本版逐机安装验收。

## v0.9.0 新增核对

完整模式显式支持入口群、登记话题群、新建及接续话题、已配置项目内的路由、各群控制和支持的审批。默认安装仍从单群开始。新增登记绑定可以追加，旧群、项目与对话绑定保持不变；新话题必须先保存其账本，历史不确定任务仍会阻止启动。完整模式不接收未登记陌生群的工作。

Codex `26.1013.4894.0` / 自带 CLI `0.163.0-alpha.10.2` 已完成本机只读兼容核对：唯一 55 工具目录、16 份相关协议文件及可达定义保持当前使用的约束，隔离后台初始化和项目读取通过。版本字符串相同仍有不同程序 SHA。此项是兼容证据，完整功能的现场验收需要另行完成。

此前桌面自动更新后旧受管会话已暂停，新普通桌面可用。升级不会自动授权 Bridge 接入新的程序或工具目录；需要重新核对和准备服务。公开版本不承诺跨任意未来 Codex 更新持续运行。

## v0.8.2 新增核对

Codex `26.1013.3656.0` / CLI `0.163.0-alpha.10.2` 在隔离空目录中真实复现：持久空闲对话可读取空队列，临时空闲对话返回匹配其 ID 的精确 `-32600` 拒绝，原因是临时对话不支持排队。v0.8.2 仅为未绑定且两次均空闲的临时对话识别此响应；仍调用原生队列接口，两次扫描全部已加载任务并核对上下文。绑定对话不得为临时对话，持久对话和其他错误仍拒绝放行。该隔离验证没有提交模型输入，不等于本机共享部署现场验收已通过。

## 已验证的核心

同一原生项目与桌面对话的飞书文字收发、桌面接续、持久队列与消息去重、状态/追加/定向停止、支持的审批交互与取消、保存结果取回、受控故障暂停及恢复普通桌面。Windows 登录、启动、正常退出保持关闭、手动重入、模型设置切换和延迟退出回执均有现场证据。

运行基线 `63d3ba7` 于 2026-10-16 完成 P4 约定范围验收：一个既有群、一个所有者。五分钟关闭证明为连续 304.295 秒/47 条原生样本，实际延迟退出回执等待 7.986 秒；最终独立清理 26 项通过。公开仓库不携带个人账本、原始会话或本机运行证据。

本版新增的安装准备工具只读探测工具目录、生成新配置，不参与模型执行。它另有自动回归与打包检查；不把这些测试写成已在其他用户电脑完成现场安装。

## 需要单独验收

- 别的桌面版本、升级后的二进制或工具目录。版本字符串相同也可能有不同 SHA；不可关闭校验。
- 每台安装的群、项目及新话题现场行为。v0.9.0 可显式启用登记群完整模式，默认安装仍固定单群；更多所有者不在当前范围内。
- Lark 国际租户及其他操作系统。
- 长时间持续运行。既有验收主要是有界窗口，不等于数天或数周的可靠性证明。

## 不承诺

桌面全部消息镜像、图片附件输入、多用户服务器、断电后的任意自动恢复、重复投递的绝对零风险、任意 App Server 版本兼容、并发双端独立隔离。正常退出会保持关闭；故障恢复到普通桌面表示消息渠道暂停，不等于 Bridge 已恢复处理消息。

共享后台与桌面工具接线依赖本机版本特性和本地信任边界。它不是云端托管服务，也不是对官方接口未来兼容性的保证。[OpenAI App Server 文档](https://learn.chatgpt.com/docs/app-server)说明了底层协议；本项目只承诺这里列明的自身验证范围。
