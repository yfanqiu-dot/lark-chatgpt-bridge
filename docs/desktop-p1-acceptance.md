# P1 现场验收

此清单是现场执行说明，**尚未执行完成**。自动化模拟不能代替真实消息收发与桌面接续证据。

## 测试对象与准备

一个只含所有者与机器人的专用飞书测试群；一个登记项目下的专用 Codex 对话。复用已有专用对话亦可。配置中固定 owner、chat、project、thread，不使用正式办公对话。

准备就绪后，明确测试群和同一机器人旧消费者的临时停用范围，再启动新消费。新旧不能同时争抢事件。保留旧启动命令以便恢复；不修改桌面调用飞书 CLI 的配置。

本次共享启动会重开桌面并影响其当前任务，需在结束当前桌面回合后通过外部终端或已准备的协调程序执行。使用 [运行说明](../README.desktop.md) 中的启动顺序；确认 host ready、bridge check 通过后才连接飞书。

## 验收操作与证据

| 操作 | 应观察到 | 必须保存 |
|---|---|---|
| 群内本人 `@QIU` 告知随机校验词 | 真实桌面对话出现这一轮，群内收到确认 | 原 messageId、turnId、回复 receipt、桌面可见结果 |
| 群内第二轮询问校验词，不重述词本身 | 沿用上下文；同一 threadId | 第二组 messageId/turnId/receipt |
| 桌面在同一对话更新校验词，再从群内第三轮追问 | 返回桌面更新后的词 | 桌面新增轮次、第三组消息和回执、归属项目 |
| 重放同一测试消息事件 | 不新增模型轮次 | messageId 唯一性与 turn 数量 |
| 本人查询状态、追加指令、停止一个专用长任务 | steer 只进当前轮；stop 定向中断；其他桌面任务继续 | expectedTurnId、终态、状态输出 |
| 请求一个安全的测试命令，分别选择同意/拒绝/取消 | 卡片说明具体操作；执行与决定一致；resolved 后按钮失效 | requestId/turnId/决定/终态；实际命令输出或未执行证据 |
| 在桌面处理已经推送到飞书的审批 | 飞书旧卡关闭，重复点击不再提交 | resolved 与旧卡拒绝结果 |
| 仅断开 bridge WebSocket，后台保持运行 | 恢复原轮次，无第二次 turn/start | 原 turnId、重连记录、最终结果 |
| 停止 bridge，再停止 host | 恢复普通桌面；历史和必要工具仍可用 | host 退出结果、普通桌面实际打开及只读工具检查 |

三轮群消息应由本人发送。自动化脚本不得冒充本人；若要以用户身份发送测试消息，需单独明确这项操作。其他群、其他发送者和机器人自身消息仅以本地事件测试验证过滤，无需向无关人员发消息。

原始证据写本机忽略目录，发布报告只保留脱敏结果。不要把密钥、完整工具环境或日常会议材料放进 Git。验收未通过时保留实际错误，不用重跑覆盖第一次失败。

## 完成标准

真实三轮与桌面接续成功、无重复执行、定向停止和审批可用、回退已核实，才标记 P1 验收通过。P2 自动新群/新对话/导出、P3 崩溃恢复与长时稳定性、P4 正式切换不随本次验收自动启动。
