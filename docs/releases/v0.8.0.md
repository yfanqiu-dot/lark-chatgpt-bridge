# QIU Bridge v0.8.0

首个可下载的 Feishu ↔ Codex Desktop 发行版。通过自己的飞书群，继续同一条真实 Codex 桌面项目对话。

## 本版内容

- 合入 P1—P4 桌面桥接、持久消息处理、审批、结果取回及 Windows 受管启动代码。
- 运行核心基于已完成单群验收的 `63d3ba7`，保留正常退出停止消息服务、配置刷新恢复及不确定请求保护。
- 新增安装准备工具：读取本机完整工具目录、生成单群配置，拒绝覆盖已有安装或接收密钥字段。
- 提供包含构建产物与生产依赖的 Windows x64 ZIP、SHA-256 校验文件，以及中英文介绍、安装、运维和兼容性说明。
- 凭据工具包含在发行包内；新用户不必复制作者的旧安装、配置、机器人或消息记录。

## 开始使用

安装 Node.js 22 LTS，下载 `qiu-bridge-v0.8.0-windows-x64.zip` 并核对 `SHA256SUMS.txt`，解压到固定目录，按包内 `README.desktop.md` 配置自己的飞书应用、项目和对话。

本分支不发布到 npm。npm 上原有 `lark-channel-bridge` 不等于这个桌面发行版。

## 验证与范围

运行基线已在 Codex `26.1007.9446.0` / Windows x64 完成单群现场验收，含真实登录、退出保持关闭、重入、延迟退出回执和清理。新增安装准备路径另有自动回归。发布提交的 Windows/macOS/Linux 测试、类型与构建状态见仓库 Actions。

首版默认一个既有群、一个所有者，关闭新话题创建。其他版本、扩群、长期运行、国际租户均需另行验证。它是社区集成，不是 OpenAI 或飞书官方产品。

## 升级与安全

已有用户保留原绑定、账本、审批记录及凭据；不要用新安装工具覆盖旧状态，也不重发历史不确定请求。具体流程见 `docs/desktop-p4-deployment.md`。发行包不含 Node.js、Codex、密钥或个人数据。
