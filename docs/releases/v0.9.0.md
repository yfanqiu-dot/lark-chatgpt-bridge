# QIU Bridge v0.9.0

增加完整桌面功能的正式受管部署方式，覆盖入口群、已登记话题群、新话题及跨配置项目路由。

- 在部署清单显式设置 `scope: "registered-topics"`，使用全部登记绑定及 `allowTopicCreation: true`；首次安装默认单群保持不变。
- 受管清单和监听心跳核对同一范围；空群数组只有搭配明确的完整模式身份才可使用，不能据此扩大默认单群范围。
- 新话题先保存绑定账本再启用。新增绑定可以追加并在重新启动后复用；原群、项目、对话及程序身份继续固定校验。
- 历史不确定输入仍需按原生证据核对。已核对的结果通过 `/result` 显式取回，保留原错误通知、原回执和证据摘要，不重发旧输入。
- 安装包包含历史版本说明，修复离线 README 中指向旧版说明的链接缺失。

本机已只读核对 Codex `26.1013.4894.0`、自带 CLI `0.163.0-alpha.10.2` 与完整工具目录；具体程序 SHA 按机器重新固定。升级后的完整功能现场核验独立进行，不能以代码测试或其他机器的结果代替。

完整功能指现有桌面后端：文字收发、同对话接续、多项目话题、状态、补充指令、定向停止、结果取回、核对和支持的审批。图片附件、桌面全部消息镜像、多用户托管及长期无人值守保证不在本版支持范围。见[完整功能部署](../desktop-p4-deployment.md#完整功能部署-v090)和[兼容性](../compatibility.md)。
