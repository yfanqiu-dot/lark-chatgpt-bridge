# QIU Bridge v0.8.1

修复飞书短暂断线时监督程序立即暂停服务、没有给 SDK 自动重连留出时间的问题。

- 同一个监听连接最多恢复三分钟，连接连续稳定五秒后放行新的模型提交；断线反复发生不会延长本次等待。
- 启用 SDK 自带保活。恢复期间持续核对原桌面、后端、监听器、完整工具目录、锁和租约；校验异常或超时仍暂停。
- 在模型提交前等待连接恢复，关闭服务或取消时可以退出等待。已提交任务和失败回执不会自动重放。
- 保存有界、脱敏的连接状态变化与恢复结果，关闭后也可定位首次断线。旧版本未保存底层连接状态，无法据旧故障反推具体网络原因。
- 兼容新版 Codex 的 `codex-app-tools-*` 管道，保留旧管道支持和全部身份校验。

已完成重连、抖动、超时、取消、异常身份/租约/锁/工具目录以及提交边界的自动回归。Codex `26.1013.3656.0` / CLI `0.163.0-alpha.10.2` 的 55 工具目录与所用协议已只读核对，隔离后台初始化和项目读取通过。新版现场收发、退出与重入仍需在部署机器重新验证，不能沿用 v0.8.0 的现场结论。

Windows x64、Node.js 22 LTS。下载 ZIP 后核对同页 SHA256SUMS。升级请使用独立目录、保留原账本及失败记录，并按[运维说明](../desktop-p4-deployment.md)完成清理和重新验收。更多群、所有者、图片附件和长期无人值守不在已验收范围内。
