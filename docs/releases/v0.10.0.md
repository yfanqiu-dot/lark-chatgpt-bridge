# QIU Bridge v0.10.0

从飞书单聊安排工作、创建专项话题，再进入对应群处理具体事项。本版作为当前已验证范围的正式发布版，面向使用自己 Windows 电脑和 Codex 的个人用户。原入口群和已登记话题保留。

## 开始使用

- 新用户：下载本 Release 的 Windows x64 ZIP 和 `SHA256SUMS.txt`，核对哈希，按[安装指南](../../README.desktop.md)配置并先验证单群。需要 Windows x64、Node.js 22 LTS、兼容且已登录的 Codex、自己的飞书机器人；包中包含生产依赖。
- 日常使用：[中文完整手册与小技巧](../user-guide.zh.md) / [English user guide](../user-guide.en.md)。包含全部命令、单聊建话题、办公案例、排队审批、文件限制和故障处理；手册也在 ZIP 内，可离线阅读。
- 已有部署：保留原项目、对话、绑定和账本，按[运维说明](../desktop-p4-deployment.md)准备新的封存部署。不要覆盖运行目录或用空账本绕过历史状态。

## 本版变化

- 显式配置 `directControl` 后，所有者在该单聊直接发文字，无需 @；SDK 允许名单与路由同时核对所有者，精确匹配单聊 ID 和 P2P 消息类型。其他人的私聊及陌生会话不接入。
- 主控绑定独立的真实 Codex 项目对话和消息账本，沿用状态、停止、追加指令、审批、去重和已保存结果取回。单聊控制不作用于其他群的任务。
- 单聊与原入口群均可使用 `/topic new <项目> <名称>` 及 `/topic resume <原消息编号>`，共用资源创建顺序与去重记录；创建结果不明时继续暂停核对。
- 新增主控入口 `/help` 和 `/topic list`。话题创建回复与话题列表提供飞书群入口，点击后在对应群 @机器人开展专项任务。
- 单聊绑定纳入部署、账本、原生状态及监督就绪范围核对。默认不启用单聊，已有部署不会因升级自动接收私聊，也不会自动迁移旧版 CLI 会话历史。
- 修复上次服务清理失败后，电脑重启仍被旧运行记录挡住的问题。每次启动保存计划绑定的原生开机证据；确认同机新的开机、旧角色退出且账本无不确定任务后，可重新执行完整准入。缺失结束记录也保留原样，不重复提交旧任务；同次开机异常、睡眠唤醒及没有开机证据的历史运行仍需核对。
- 修复开机后桌面任务活动时等待接入被错误中断：监听启动前核对主机锁已持有、话题锁空闲，启动后才要求两把锁均已持有。外来锁、身份变化、审批及不确定队列仍阻断，不跳过原生空闲核对。

保留 v0.9.5 的登录启动及完整恢复后重新准入修复。新安装或升级仍需现场验证，相关设置见[运维说明](../desktop-p4-deployment.md)。

## 验证和已知边界

本版开发基线通过 1423 项自动测试、类型检查、构建和文档链接检查；Windows、Linux、macOS CI 验证代码，桌面运行支持仍为 Windows x64。单聊直连、结果取回、创建话题及主控隔离有现场验证；最新启动修复完成真实 Windows 重启后自动接入和约十五分钟有限健康观察（18 项核对、448 份样本）。该次只读观察未提交新模型输入，不替代每台新安装的收发验收，也不代表长期无人值守保证。

当前没有统一话题改名、归档、停用、解绑、删除或清空队列命令。两侧改名不自动同步；删除绑定对话可能影响全局启动。`/stop` 不清空排队请求，`/result` 返回最近已保存答案而非保证是最新输入。图片附件输入、多用户托管和完整桌面镜像不在本版范围。飞书文档、日程和任务需要另配工具及授权。Windows 沙盒初始化错误仍可能需要桌面处理。详见[完整边界](../compatibility.md)和[用户手册](../user-guide.zh.md)。

## English

v0.10.0 adds explicit owner-only DM control, topic discovery and creation links, and Windows reboot admission fixes. A complete [English user guide](../user-guide.en.md) is included. Download the ZIP and checksum from this release; installation instructions are currently in Chinese. Windows x64 and one configured owner are supported. Topic lifecycle commands, attachment input and guaranteed unattended operation are outside this release. Preserve existing bindings and ledgers when upgrading and verify your installation locally.
